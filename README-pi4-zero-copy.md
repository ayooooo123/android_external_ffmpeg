# Raspberry Pi 4 zero-copy video (branch `pi4-zero-copy`)

This branch is one of four that together give smooth 4K HEVC (8- and 10-bit) on a Raspberry Pi 4 running Android 15.
See [README-pi4-zero-copy.md in android_external_ffmpeg_codec2](https://github.com/ayooooo123/android_external_ffmpeg_codec2/blob/pi4-zero-copy/README-pi4-zero-copy.md) for what changed, how to build it, and test results.
